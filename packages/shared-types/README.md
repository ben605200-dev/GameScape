# @gamescape/shared-types

TypeScript types shared between the desktop app, the website, and tooling — generated from (or kept in sync with) the Rust core.

**Status:** pending (Phase 2). The sync strategy (generated bindings vs hand-maintained types with a CI drift check) is decided at the start of Phase 2.

Contents will include: catalogue entry types, wallpaper/layout/widget models, API/IPC payloads, and the catalogue index schema types.
