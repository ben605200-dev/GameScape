# @gamescape/ui

The GameScape design system: design tokens and components shared by the app and the website.

**Status:** pending (Phase 1 deliverable, immediately after the app scaffold).

Contents will include:

- Design tokens (colour themes, typography, spacing, radius, elevation, motion) as CSS variables + typed definitions.
- Shared primitives (buttons, cards, badges, inputs) built on the token system.

Rules: light and dark themes from day one; WCAG 2.2 AA contrast targets; the anti-pattern list in the UI/UX specification is enforced at review.
