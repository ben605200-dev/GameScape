# Support

Thanks for using GameScape! Here is how to get help.

## Where to go

| Need | Where |
|---|---|
| Bug report | [Issues](../../issues/new?template=bug_report.yml) — use the bug template |
| Feature request | [Issues](../../issues/new?template=feature_request.yml) — use the feature template |
| Questions & ideas | Discussions (to be enabled before the first public release) |
| Report a wallpaper / gallery entry | [Content report](../../issues/new?template=content_report.yml) |
| Copyright takedown | [Takedown request](../../issues/new?template=copyright_takedown.yml) |
| Security vulnerability | **Private report only** — see [SECURITY.md](SECURITY.md) |

## Before opening an issue

1. Check the documentation in [`docs/`](docs/README.md) and the FAQ (published with the website).
2. Search existing issues — someone may have hit the same problem.
3. Make sure you are on the latest release (Settings → About → Check for updates).
4. For performance or desktop-layer problems, use the in-app diagnostics export
   (Settings → About → Diagnostics). **Review it before sharing** — remove anything you don't want to make public.

## What to expect

- This is a small, independent project. Response times are best-effort.
- Security reports are handled privately and take priority.
- Content and conduct reports are reviewed by maintainers; see the Code of Conduct and the site's takedown process.
